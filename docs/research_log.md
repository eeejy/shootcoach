## 3. 실제 영상에서 확인된 것 (합성 데이터로는 몰랐던 것)

1. **관절 추출은 실제 사수에게도 잘 된다** — 어깨 87~100%, 팔꿈치 54~98%, 손목 49~70% 프레임에서 검출 (신뢰도 0.5 이상). M4에서 프레임당 21ms (단독 실행, `docs/benchmark.json`).
2. **편집 컷을 반동으로 오인했다** → 컷 감지(색 분포 + 픽셀 차이) 추가. 이제 홍보 영상에서는 "보류"로 답한다. **실제 사용은 편집 없는 연속 촬영 영상이어야 한다.**
3. **사수 등이 화면을 채우면 뒤쪽 인형 표적을 사람으로 잡는다** → 촬영 위치 표준(측면 2m, 전신이 보이게)이 필수.
4. **배경음악이 깔린 영상에서는 총성으로 격발을 못 찾는다** → 원본 녹화(음악 없음)에서만 총성 검출이 동작. 없으면 반동 동작으로 추정.
5. **합성으로만 학습한 탄공 검출기는 실루엣 표적의 선 끝을 탄공으로 오검출** → 선 그림 음성 샘플을 넣은 v2로 재학습: 오검출 15·16·45개 → 2·3·15개. **그러나 실제 탄공도 대부분 놓침** — 합성 탄공은 실제 찢김·그림자를 충분히 닮지 않았다. **실제 해경 표적지 50~100장 파인튜닝이 반드시 필요**.

## 6. 2차 개편 (2026-09-29~30)

### 6-1. 새로 알게 된 사실
- **해경 표적에는 마커가 없다.** 마커 기반 보정을 버리고, 표적마다 인쇄된 **검은 조준 원**을 기준으로 삼았다. 해경 원형 표적 실사진 11장 모두에서 표적을 찾았고, 하반신(속사) 표적과 25m 영점 표적은 원형이 아니라고 정상 판별했다.
- **표적은 두 종류:** 완사용 원형 표적, 속사용 하반신 실루엣 표적. 나머지 사진은 참고용.
- **교관 자료 2종**(탄착군 원인 분석 마스터 스펙, 다중 변수 진단 알고리즘)은 "좌하 = 방아쇠" 식 1차원 매핑을 명시적으로 배제한다. 성분 분해 + 가중합 + 교관 검증 구조로 진단 엔진을 다시 썼다.
- **서울청 STARS 과제의 요령:** 한 장에 쏜 발수를 알면 검출 결과를 발수에 맞춰 보정할 수 있다. 신뢰도 기준 조정, 뭉친 탄공 나누기에 그대로 적용했다.

### 6-3. 해경 실사진에서 확인된 것
1. **선명한 원본 사진은 거의 완벽**, 흐리고 해상도가 낮은 사진(카톡 전달본)은 절반 가까이 놓친다. 촬영 가이드가 모델보다 중요하다.
2. **검은 원 안의 탄공은 AI가 자주 놓친다.** 뒤에서 빛이 비쳐 '밝은 점'으로 보이는 점을 이용해 영상처리로 보충했다. 처음엔 인쇄 숫자와 가운데 +를 탄공으로 잡아 정밀도가 0.72까지 떨어졌고, 축 위 영역을 빼고 나서 0.95로 회복했다.
3. **링 간격 25mm 가정이 실제 인쇄 링과 겹친다** — 오버레이로 확인. 실물 측정으로 최종 확인 필요.
4. **검은 원 가장자리에 맞은 탄이 표적 위치를 끌어당겼다.** 7점 경계 바로 바깥의 어두운 탄공이 검은 원과 한 덩어리로 잡히면 원 중심이 탄착군 쪽으로 10mm 넘게 밀렸다. 원 둘레에서 벗어난 점을 빼고 다시 맞추는 방식으로 고쳤다(`locate._refine_ellipse`, 회귀 테스트 추가).

### 6-4. 최종 모델
- YOLO11s, 입력 960px, 30에포크(맥북 M4 GPU 6.7시간). 공개 검증 mAP50 0.79 / mAP50-95 0.41.
- 추론 때 좌우 뒤집기·배율 TTA를 켜면 해경 실사진 F1이 0.85 → 0.88로 오른다. 표적을 잘라 크게 넣거나 1280px로 넣으면 오히려 떨어졌다(학습 때 표적 전체 크기에 맞춰졌기 때문).
