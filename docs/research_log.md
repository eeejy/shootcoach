## 3. 실제 영상에서 확인된 것 (합성 데이터로는 몰랐던 것)

1. **관절 추출은 실제 사수에게도 잘 된다** — 어깨 87~100%, 팔꿈치 54~98%, 손목 49~70% 프레임에서 검출 (신뢰도 0.5 이상). M4에서 프레임당 58~76ms (학습과 동시 실행 기준).
2. **편집 컷을 반동으로 오인했다** → 컷 감지(색 분포 + 픽셀 차이) 추가. 이제 홍보 영상에서는 "보류"로 답한다. **실제 사용은 편집 없는 연속 촬영 영상이어야 한다.**
3. **사수 등이 화면을 채우면 뒤쪽 인형 표적을 사람으로 잡는다** → 촬영 위치 표준(측면 2m, 전신이 보이게)이 필수.
4. **배경음악이 깔린 영상에서는 총성으로 격발을 못 찾는다** → 원본 녹화(음악 없음)에서만 총성 검출이 동작. 없으면 반동 동작으로 추정.
5. **합성으로만 학습한 탄공 검출기는 실루엣 표적의 선 끝을 탄공으로 오검출** → 선 그림 음성 샘플을 넣은 v2로 재학습. 그래도 **실제 해경 표적지 50~100장 파인튜닝이 반드시 필요**.
